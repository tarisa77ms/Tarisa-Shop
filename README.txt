# TARISA SHOP

Website toko online bertema fashion & accessories untuk tugas/praktikum HTML, CSS, dan JavaScript.

## Struktur Folder

Tarisa_Shop/
├── index.html
├── style.css
├── script.js
└── README.txt

## Cara Menjalankan

1. Buka folder `Tarisa_Shop`.
2. Klik dua kali `index.html`.
3. Website akan terbuka di browser.
4. Bisa juga dibuka/edit menggunakan Notepad++.

## Fitur

- Home / landing page
- Menu Produk dengan CSS dropdown
- Kategori Fashion, Sepatu, Tas, Aksesoris
- Search produk
- Filter produk
- Tambah ke keranjang
- Ubah jumlah barang
- Hapus barang
- Total harga
- Register / Daftar
- Login / Masuk
- Logout
- Checkout simulasi
- Validasi form dengan JavaScript
- Penyimpanan akun, status login, dan keranjang memakai localStorage
- Responsive untuk layar kecil

## Catatan Login

Ini adalah website frontend untuk praktikum. Data akun disimpan di `localStorage` browser, sehingga belum menggunakan database/server.

Contoh alur:
1. Klik `Daftar`
2. Isi Nama, Email, Password, Alamat
3. Klik `Daftar`
4. Login dengan email dan password yang dibuat
5. Setelah login muncul nama pengguna dan tombol `Logout`
6. Klik `Logout` untuk keluar

## Kaitan dengan materi dosen

- Pertemuan 3: HTML table/form/hyperlink dan struktur halaman.
- Pertemuan 4-5: CSS selector, class/id, external stylesheet, background, layout, border-radius.
- Pertemuan 7: CSS dropdown menu.
- Pertemuan 8: JavaScript, function, form validation, DOM, event, dan interaksi halaman.

## Jika dosen meminta Java

Kode di proyek ini menggunakan JavaScript (bukan bahasa Java), karena materi yang dilampirkan membahas JavaScript. Jika tugas berikutnya mewajibkan Java sebagai backend/database, frontend ini dapat dilanjutkan menjadi JSP/Servlet + MySQL.
